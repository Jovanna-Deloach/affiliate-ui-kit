# Foundations

Everything a component reads is a **role**, set by the theme on `[data-theme]` and, for wayfinding colour only, by `[data-category]`. Components never carry their own colours, sizes or shadows, so the same page in another theme is another publication. The source of truth is `src/kit/theme/kit.css`.

## Themes

A theme is the whole art direction: faces, palette, radii, elevation, density. Apply it with `data-theme` on any ancestor.

| `data-theme` | Publication | Character | Faces (display · text · micro) | Shape |
| --- | --- | --- | --- | --- |
| `atelier` | Caliber, luxury goods (watches) | A museum catalogue, not a newspaper: objects get room, prose is set like a book | Newsreader (headlines 300, titles 400) · Plus Jakarta Sans · JetBrains Mono | 6px cards, 4px controls, generous density |
| `assay` | Proving Ground, lab-tested health and performance | A lab report you can read in ten seconds, printed on good paper | Playfair Display (headlines 400, titles 500) · Inter · JetBrains Mono | 8px cards, 6px controls, compact density |

**Categories.** A publication with several beats is one theme. Its sections differ only by `data-category` (`watches`, `supplements`, `running`), which sets the category accent: the masthead’s section marker, award text in tables, telemetry bars and verification stamps. Wordmark, surfaces, type and the buy action stay the publication’s. In Assay, `supplements` is botanical emerald and `running` is international vermilion; in Atelier the category accent is always brass.

## Type: three voices

Set type only with these utilities. No Tailwind font sizes (`text-sm`, `text-[15px]`), no fourth face.

| Voice | Utility | Use |
| --- | --- | --- |
| Display serif | `t-display` | The page title (H1), capped at `max-w-measure-title` (22ch) |
| | `t-headline` | Section headings (H2) |
| | `t-title` | Product titles: the deep dive, the feature verdict card |
| | `t-name` | Product names in compact cards and catalogue entries (1.25rem) |
| | `t-name-sm` | Product names in table rows (1.0625rem) |
| | `t-quote` | Pull-quotes, italic; wrap the opening mark in `kit-hang` |
| | `t-score`, `t-stat` | Hero figures: the composite score (2.5rem), the testing card’s counts (2.25rem) |
| Text sans | `t-lead` | The dek, a verdict, the synthesis line |
| | `t-body` | Reading copy: 17px on 1.68, at most `max-w-measure` (65ch) wide |
| | `t-ui` | Names, labels and controls (15px) |
| | `t-small` | Secondary text (14px) |
| | `t-caption` | Captions and notes (12px) |
| | `t-button` | Button faces: 11px tracked capitals |
| | `t-price` | The buy box’s price: 1.5rem bold |
| | `t-figure`, `t-figure-table`, `t-figure-xl` | Figures: tabular, lining numerals |
| Mono micro-caps | `t-micro` | Eyebrows, data headings, column heads, stamps: 11px, +0.08em, 600 |
| | `t-micro-sm` | Pills on photographs, awards in rows: 10px |

Hierarchy: the display serif is for what reads as a title or a hero figure; the text sans is for reading and acting; micro-caps label and never speak (one short phrase, never a sentence, written in sentence case). Mark every figure that should align in a column with `data-numeric`; the checks fail one that is not in tabular numerals.

## Layout

- **The page well**: `kit-well` is the 1200px (75rem) column with its gutters (1rem, 1.5rem from 768px). Every band of a page sits in it, so every band shares one left edge.
- **Sections** are separated by `mt-chapter`, the theme’s section gap (Atelier 80–128px, Assay 64–96px, fluid). The first band after the article header uses `mt-12 md:mt-16`; deep dives stack with `gap-10`.
- **Measure**: reading text at most `max-w-measure` (65ch), set with `text-wrap: pretty`; headings are balanced.
- **Spacing** for padding, margin and gap uses only these steps of the 4px scale: 0.5, 1, 1.5, 2, 2.5, 3, 3.5, 4, 5, 6, 8, 10, 12, 16, 20, 24, 32.
- **Alignment**: columns that sit side by side start on one line (`items-start`). Bottom alignment (`items-end`, `self-end`, `place-*-end`) is not used; right-align with `text-right` or an auto margin.
- **Container queries**: blocks and components lay out by their own width, not the viewport (`@container`, then `@sm` 24rem, `@md` 28rem, `@xl` 36rem, `@2xl` 42rem, `@3xl` 48rem, `@4xl` 56rem, `@5xl` 64rem), so a block looks right in whatever column it is placed. A phone is a layout, not a squeeze: when width runs out a part drops a word it can spare, never a name or a price.

## Surfaces

Three layers, never more: **ground** (the page), **paper** (cards), **well** (a recess inside a card). Containers nest twice at most.

| Utility | What it is |
| --- | --- |
| `kit-card` | Paper with a 1px `line` border, the theme’s radius and its ambient shadow |
| `kit-card-feature` | A warmer paper lifted a step further: the lead pick’s verdict card only |
| `kit-recess` | A well inside a card, with a strong hairline: the buy box’s offer card |
| `kit-studio` | The radial studio well behind every product photograph |
| `kit-object` | The soft contact shadow under a cut-out product |

Radii are roles too: `rounded-box` (cards), `rounded-ctl` (controls and pills), `rounded-media` (photographs), `rounded-full`. Elevation comes only from `kit-card` and `kit-card-feature`; no other shadow.

## Interaction and motion

- `kit-focus` gives every interactive element the same focus ring: 2px in the action colour, 2px off the edge.
- `kit-link` is the inline link: a thin, low underline that darkens on hover.
- Buttons and retailer rows are at least 44px tall.
- Motion is colour only: 180ms on the theme’s easing, cut to 1ms when the reader prefers reduced motion. No scripted animation.

# Color

Use the token, never the value. Every token is a Tailwind utility, set by the theme (`data-theme`); the category tokens also change with `data-category`. Tailwind’s own palette is removed, so `bg-blue-500` or `text-gray-700` does not exist, and there are no `dark:` overrides: a theme sets every color. The page and the cards are white; only a recess or a photograph’s backdrop is a cool gray. No beige, cream or parchment, and no tinted page. Color is never the only signal: a pass, a fail or a warning always has a word or an icon too.

## Surfaces

| Utility | Job | Atelier | Assay |
| --- | --- | --- | --- |
| `bg-surface-primary` | The page canvas: white, like the cards; a card stands on it by its hairline and shadow | `#ffffff` | `#ffffff` |
| `bg-surface-raised` | Cards, fields, menus and dialogs (the lead pick’s card too: it is lifted by its shadow, not a color) | `#ffffff` | `#ffffff` |
| `bg-surface-sunken` | A recess inside a card | `#edf1f6` | `#eceff3` |
| `bg-surface-inverse` | Ink as a fill: tooltips, an active chip, the current-price marker | `#121820` | `#111418` |

## Earlier names

Parts that have not moved to the names above still use the earlier ones, which now resolve to the same tokens. Use the new names in anything you write; the earlier ones go when the last part has moved.

| Earlier | Now |
| --- | --- |
| `ground`, `paper`, `paper-feature`, `well` | `surface-primary`, `surface-raised`, `surface-raised`, `surface-sunken` |
| `fg`, `fg-body`, `fg-muted` | `text-primary` (as a fill, `bg-surface-inverse`), `text-prose`, `text-muted` |
| `line`, `line-strong` | `border-subtle` (as a fill, `bg-rule`), `border-bold` (as a fill, `bg-rule-bold`) |
| `accent`, `accent-hover`, `accent-soft`, `on-accent` | `action`, `action-hover`, `action-subtle`, `on-action` |
| `accent-category`, `accent-category-ink`, `accent-category-soft` | `category`, `text-category`, `category-subtle` |
| `pass`, `fail`, `warn` (and `-soft`) | `success`, `danger`, `warning` (and `-subtle`) |
| `award-line` | `border-award` |

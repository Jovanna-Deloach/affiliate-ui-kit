# Color

Use the role, never the value. Every role is a Tailwind color (`bg-`, `text-`, `border-`), set by the theme; the category roles also change with `data-category`. Surfaces are cool whites and grays: no beige, cream or parchment. Color is never the only signal: a pass, a fail or a warning always has a word or an icon too.

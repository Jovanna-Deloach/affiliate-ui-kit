# Color

Use the role, never the value. Every role is a Tailwind color (`bg-`, `text-`, `border-`), set by the theme; the category roles also change with `data-category`. Color is never the only signal: a pass, a fail or a warning always has a word or an icon too.

## Surfaces and lines

| Role | Job | Atelier | Assay |
| --- | --- | --- | --- |
| `ground` | The page canvas: warm and toned, never pure white | `#f4f0e8` | `#f5f3ee` |
| `paper` | Cards | `#faf8f4` | `#ffffff` |
| `paper-feature` | The lead pick’s card only | `#fdfcf9` | `#fffdf9` |
| `well` | A recess inside a card | `#ebe6dc` | `#efece6` |
| `line` | Hairlines: cards, tables, rows | `#e2ddd3` | `#e5e2dc` |
| `line-strong` | Outlines and strong rules | `#cec6b8` | `#d3cec5` |
